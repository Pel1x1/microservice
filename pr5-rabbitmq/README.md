# ПР5. RabbitMQ — четыре самостоятельных решения

У каждого участника своя папка: код **только своего варианта** (параметры зашиты константами
в начале файлов). Задания 1 и 2 выполняются по одному и тому же варианту.

| Участник | Папка | Вариант | Тема |
|---|---|---|---|
| Начинкин И.С. | `nachinkin/` | 1 | заказы |
| Гидаятов К.Г. | `gidayatov/` | 2 | импорт прайс-листов продавцов |
| Киселев К.С. | `kiselev/` | 3 | пересчёт рейтинга по отзывам |
| Сошнин Н.А. | `soshnin/` | 1 | передача посылок в службу доставки |

Варианты распределены по порядку (1, 2, 3, 1), чтобы были покрыты все три; у Начинкина и Сошнина
вариант совпадает, поэтому у них разные имена, тексты и предметная начинка.

## Запуск

```bash
pip install -r requirements.txt
cd <фамилия>
python task1/consumer.py            # терминал 1
python task1/producer.py            # терминал 2
python task2/consumer.py            # воркер; запустите два-три экземпляра
python task2/producer.py [routing_key] [текст ...]
```

Скрипты можно запускать из любой папки: путь к `common.py` строится от расположения файла.

По умолчанию используется учебный сервер `51.250.26.59` (guest/guest123). Локальный брокер:

```bash
docker run -d --name rabbitmq -p 5672:5672 -p 15672:15672 rabbitmq:3-management
export RABBIT_HOST=localhost RABBIT_PASSWORD=guest      # Windows: set RABBIT_HOST=localhost
```

Результаты проверки каждого решения (с перезапуском брокера) — в `<фамилия>/run_log.txt`.
